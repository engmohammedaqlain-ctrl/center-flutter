# Docs — معاينة كشوفات PDF (قبل الدمج في التطبيق)

> **لا تُدمج في `lib/` إلا بعد موافقتك الصريحة («اه»).**
> الملفات هنا بلغة Dart وبنفس أسلوب `pdf` المستخدم في Flutter حتى النقل يكون نسخة شبه حرفية.

## الحساب التجريبي (مرجع البيانات)
- مستخدم المنشأة: `amal` / `amal2026`
- المدير: كلمة المرور `amal2027`

## الكشوف الستة

| # | الملف | المقابل على الويب | الاتجاه |
|---|--------|-------------------|----------|
| 1 | `reports/01_attendance_report.dart` | كشف الحضور والغياب | A4 عرضي |
| 2 | `reports/02_class_roster_report.dart` | كشف بيانات وحضور طلاب الصف | A4 طولي |
| 3 | `reports/03_passwords_students.dart` | كشف كلمات مرور الطلاب | A4 طولي |
| 4 | `reports/04_passwords_parents.dart` | كشف كلمات مرور أولياء الأمور | A4 طولي |
| 5 | `reports/05_passwords_both.dart` | كشف كلمات مرور البوابة (كلاهما) | A4 طولي |
| 6 | `reports/06_grades_report.dart` | كشف العلامات (إدارة + معلم) | A4 طولي |

## قواعد مشتركة (مهمة)
1. **رأس الجدول يتكرر** في كل صفحة جديدة عند امتداد الجدول (`TableHelper` / header group).
2. **الهوامش ثابتة** (طولي ≈ 8–10mm، عرضي ≈ 6–8mm) كما في الويب.
3. ترويسة الوثيقة (اسم المدرسة · العنوان · التاريخ/العام) في أعلى كل صفحة.
4. التوقيعات في ذيل الكشف (مرة في نهاية المستند أو حسب الويب).
5. كلمات المرور بلون برتقالي على الشاشة؛ في PDF الطباعة تبقى واضحة (برتقالي خفيف أو أسود حسب اعتمادك).
6. **خط PDF:** `NotoNaskhArabic` تحت `assets/fonts/pdf/` (تقارير متصلة وواضحة؛ لاتيني احتياطي للترقيم).

## توليد المعاينة
من جذر المشروع:

```bash
dart run Docs/generate_previews.dart
```

المخرجات: `Docs/out/*.pdf`

## الاعتماد
افتح ملفات `Docs/out/` وراجع الشكل. إذا وافقت اكتب **اه** في المحادثة — عندها فقط تُنقل إلى التطبيق (إدارة + بوابة المعلم حيث يلزم).
